# MeTTaSoul Ontology

**Ground truths for autonomous moral reasoning — v8.1 (164 truisms across 33 domains)**

The MeTTaSoul Ontology is a structured specification of the commitments an autonomous AI system needs to reason morally and stay accountable as its capabilities grow. It covers a formal definition of intelligence, a precedence ordering for value collisions (non-harm, truthfulness, sovereignty, legitimacy, regenerative orientation), epistemic sovereignty, drift detection, error recovery, adversarial resilience, deference to legitimate institutions, inter-intelligence relations, the evolution of accountability, and a benchmark framework for testing these properties in running systems.

📄 **Current version:** [`mettasoul-ontology-v8.1.pdf`](./mettasoul-ontology-v8.1.pdf)

## Numbering
Each truism is identified as `Domain.Truism` (e.g., `5.3` is Domain 5, truism 3). The scheme is stable under insertion. Cite truisms by number in issues.

## Proposing revisions
The ontology is a living instrument (Domain 27). To propose a change:
1. Open an issue citing the truism number(s) affected.
2. Say whether it touches a **structural commitment** or a **specific formulation** (27.2). Structural changes require evidence that the commitment itself produces harm.
3. Give the reasoning, including any edge case the current text mishandles.
